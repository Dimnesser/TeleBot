# Запуск бота на Android через Termux

Бот будет работать прямо на телефоне. Учти сразу: пока телефон выключен,
перезагружается или Android прибивает Termux ради экономии батареи, бот
недоступен. Для постоянной работы лучше подойдёт сервер, но для проверки
и личного пользования этого хватает.

## Что понадобится

- Android 7 или новее, около 2 ГБ свободного места
- **Termux из F-Droid или GitHub**, не из Google Play. Версия из Play
  заброшена, на ней установка сломается:
  <https://f-droid.org/packages/com.termux/>
- Токен бота от [@BotFather](https://t.me/BotFather)
- Ключ Anthropic API из консоли <https://console.anthropic.com>

## Установка одной командой

Открой Termux и сначала обнови систему целиком:

```bash
apt update && apt full-upgrade -y
```

Это обязательный первый шаг, и он занимает несколько минут. Termux обновляет
пакеты непрерывно, и установка одного свежего пакета поверх старой базы ломает
`curl`: он потянет библиотеку, которой ещё нет в системе.

Здесь именно `apt`, а не привычный `pkg`. Команда `pkg` — это обёртка, которая
перед работой проверяет зеркала при помощи `curl`, поэтому со сломанным `curl`
она не запустится вовсе. У `apt` такой зависимости нет.

Дальше:

```bash
apt install -y curl && \
curl -fsSL https://raw.githubusercontent.com/Dimnesser/TeleBot/claude/telegram-ai-assistant-pfzidg/scripts/termux-install.sh \
  -o ~/termux-install.sh && bash ~/termux-install.sh
```

Скрипт поставит Python и Git, заберёт код в `~/TeleBot`, создаст окружение
и установит зависимости.

> **Про долгую сборку.** Двум библиотекам, `pydantic-core` и `jiter`, нужны
> бинарники на Rust, а готовых сборок под Android нет. Если pip не найдёт
> готовые пакеты, скрипт поставит Rust и соберёт их на месте: это от 15 до
> 40 минут. Держи телефон на зарядке и не сворачивай Termux — Android любит
> убивать фоновые процессы. Прогресс идёт, даже когда вывод замирает.

## Запуск

Одна команда делает всё: доставит зависимости, спросит токен и ключ, если их
ещё нет, подберёт модель и запустит бота.

```bash
bash ~/TeleBot/scripts/termux-run.sh
```

Спросит ровно два значения:

1. **Токен бота** от [@BotFather](https://t.me/BotFather).
2. **Ключ AI**. Подойдёт ключ любого из поддерживаемых сервисов, провайдер
   определится сам по виду ключа.

Бесплатные ключи выдают здесь:

| Сервис | Где взять | Вид ключа |
|---|---|---|
| Google Gemini | https://aistudio.google.com/apikey | `AIza...` |
| Groq | https://console.groq.com/keys | `gsk_...` |

Карту привязывать не нужно ни там, ни там. Если модель по умолчанию у
провайдера окажется недоступна, бот спросит у него список моделей и выберет
рабочую сам.

Поменять ключ позже:

```bash
cd ~/TeleBot && ./.venv/bin/python scripts/setup_keys.py
```

Обновить бота до свежей версии:

```bash
bash ~/TeleBot/scripts/termux-update.sh
```

## Проверка перед запуском

```bash
cd ~/TeleBot && ./.venv/bin/python main.py --check
```

Команда ничего не запускает: она спрашивает Telegram, кто мы, делает
крохотный запрос к модели и проверяет, что история пишется на диск. Отчёт
выглядит так:

```
✅ Telegram: бот @твой_бот
   id 123456789
✅ Модель отвечает: claude-opus-5
✅ История пишется в data/history.json
✅ Веб-поиск включён

✅ Всё готово. Запускай: python main.py
```

Если строка красная, в ней же написано, что чинить.

## Что дальше

Скрипт берёт wake lock, чтобы Android не усыпил процесс, и перезапускает
бота, если тот упал. Остановить — `Ctrl+C`.

В логе должна появиться строка вида
`Бот @твой_бот запущен, Google Gemini, модель gemini-2.5-flash`.
После этого открывай Telegram и пиши боту `/start`.

## Автозапуск после перезагрузки

Установи **Termux:Boot** из F-Droid, открой его один раз, затем:

```bash
bash ~/TeleBot/scripts/termux-autostart.sh
```

Теперь бот стартует сам при включении телефона.

## Чтобы Android не убивал бота

- В настройках Android сними ограничения батареи для Termux:
  «Батарея» → «Без ограничений» (путь отличается у разных производителей).
- На Xiaomi, Huawei, Samsung и Oppo дополнительно закрепи Termux в списке
  недавних приложений и включи автозапуск в фирменной оболочке.
- Wake lock виден в шторке уведомлений Termux. Если он пропал, бот, скорее
  всего, усыплён.

## Обновление

```bash
cd ~/TeleBot && git pull && ./.venv/bin/pip install -r requirements.txt
```

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `CANNOT LINK EXECUTABLE "curl"`, `cannot locate symbol` | Частичное обновление Termux. Лечится командой `apt update && apt full-upgrade -y`, затем повтори установку |
| `pkg` падает с той же ошибкой про curl | `pkg` сам вызывает `curl`. Делай то же самое через `apt`, у него этой зависимости нет |
| `There is no current event loop` | Старый python-telegram-bot на свежем Python. Лечится `bash ~/TeleBot/scripts/termux-update.sh` |
| `Это не Termux` | Скрипт запущен не в Termux |
| Сборка падает на `pydantic-core` или `jiter` | `apt install -y rust binutils`, затем повторить установку |
| `newer than PyO3's maximum supported version` | Termux ставит самый свежий Python. Выполни `export PYO3_USE_ABI3_FORWARD_COMPATIBILITY=1` и повтори установку |
| `Ошибка конфигурации: Не задан TELEGRAM_BOT_TOKEN` | Не заполнен `.env` |
| `Ключ доступа к модели недействителен` | Неверный `ANTHROPIC_API_KEY` |
| `Достигнут лимит бесплатного тарифа` | Упёрся в квоту Gemini или Groq. Подожди или смени модель |
| `Модель не найдена` | Неверный `AI_MODEL`. Проверка `--check` покажет список доступных |
| `На счёте Anthropic закончились средства` | Ключ верный, но баланс пуст. Купи кредиты в консоли, раздел Plans & Billing. Подписка Claude Pro на API не распространяется |
| Бот молчит в группе | В группах он отвечает только на упоминание `@имя_бота` или на ответ своему сообщению |
| `Нет связи с Telegram` при проверке | Нет интернета или провайдер блокирует Telegram: включи VPN |
| Бот замолкает через время | Android усыпил Termux: сними ограничения батареи и проверь wake lock |
| Кончилось место при сборке | Освободи место, сборке Rust нужно около 2 ГБ |

Логи бота идут прямо в окно Termux. Если что-то непонятно — пришли последние
строки вывода.
