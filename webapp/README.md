# Brainrot Battle — Mini App

Веб-версия бота (Telegram Mini App): кейсы, апгрейдер, краш, дайсы, батл,
квесты, розыгрыши, бонусы (стейкинг + рефералы) и FAQ в виде обычной
веб-страницы внутри Telegram, вместо инлайн-кнопок в чате. Работает поверх
того же кода и той же базы, что и бот (`webapp/api.py` — тонкий HTTP-слой над
`bot.database.repo` и `bot.services`, игровая логика нигде не продублирована).

## Как это устроено

- `webapp/server.py` — aiohttp-сервер, отдаёт статику (`webapp/static/`) и
  API (`webapp/api.py`). Запускается в том же процессе и event loop'е, что и
  long-polling бот — см. `bot/app.py` (`await run_webapp(bot)` перед
  `dp.start_polling(bot)`).
- `webapp/static/` — фронтенд без сборки: `index.html` + `css/app.css` +
  `js/app.js` (vanilla JS, роутинг по `location.hash`). Открывается в
  WebView Telegram через SDK `telegram-web-app.js` (грузится с
  `telegram.org` прямо в `index.html`).
- `webapp/auth.py` — проверка `initData`, которую Telegram передаёт
  фронтенду (подпись HMAC-SHA256 секретом от `BOT_TOKEN`, алгоритм — ровно
  тот, что в официальной документации Telegram).

## Локальный запуск

Бот и Mini App стартуют вместе одной командой:

```
python main.py
```

Mini App поднимется на `http://localhost:8080` (порт — `WEBAPP_PORT` в
`.env`). Просто открыть его в обычном браузере **не получится в реальном
режиме** — без `Telegram.WebApp.initData` бэкенд отвечает `401
unauthorized` на любой `/api/*`-запрос (это и есть проверка, что открыли
именно из Telegram, а не кто угодно).

### Проверка в браузере без Telegram (dev-режим)

Для локальной отладки вёрстки/логики без реального Telegram в `.env`
временно поставь:

```
WEBAPP_ALLOW_DEV_AUTH=true
```

и перезапусти бота. После этого `http://localhost:8080` можно открыть в
обычном браузере — при первом запросе он спросит любой числовой Telegram id
для теста (сохранится в `localStorage`). **Никогда не включай это на адресе,
пробрасываемом наружу (ngrok и т.п.)** — с этим флагом любой человек с
доступом к URL может представиться любым `tg_id` и тратить чужие демо-фишки
или реальный баланс. Верни `WEBAPP_ALLOW_DEV_AUTH=false` перед тем, как
пробрасывать адрес наружу кнопкой в боте.

## Чтобы кнопка «🎮 ОТКРЫТЬ MINI APP» появилась в боте

Telegram принимает `web_app`-кнопку только на **https**-адресе. Свой домен
не нужен — самый быстрый бесплатный вариант это `ngrok`:

1. Установи ngrok (https://ngrok.com/download), один раз `ngrok config
   add-authtoken <токен из личного кабинета ngrok, бесплатная регистрация>`.
2. Запусти бота (`python main.py`), в отдельном терминале:
   ```
   ngrok http 8080
   ```
3. Ngrok покажет адрес вида `https://xxxx.ngrok-free.app` — пропиши его в
   `.env`:
   ```
   WEBAPP_URL=https://xxxx.ngrok-free.app/webapp
   ```
4. Перезапусти бота — кнопка «🎮 ОТКРЫТЬ MINI APP» появится первой в
   боковом меню (`/start` → «☰ МЕНЮ», либо сразу в приветствии).

Бесплатный ngrok-адрес меняется при каждом перезапуске туннеля — для
постоянного адреса на бесплатном тарифе есть статический домен (в личном
кабинете ngrok, раздел Domains), его можно закрепить за собой один раз и
использовать всегда одним и тем же в `WEBAPP_URL`.

**BotFather настраивать не обязательно** — `web_app`-кнопка на inline-
клавиатуре работает на любом https-адресе без регистрации. Регистрация в
BotFather (`/newapp`, `/setmenubutton`) нужна только если понадобится
постоянная кнопка Mini App в поле ввода чата (рядом со скрепкой) — это
отдельная возможность, в текущей версии не задействована.

## Что уже перенесено в Mini App

Кейсы (лента по категориям + открытие), апгрейдер, краш (поллинг вместо
живой анимации в чате), дайсы, батл, квесты, розыгрыши, бонусы (стейкинг +
рефералы), профиль, FAQ.

Раздел пополнения баланса (обменник брейнротами/гирсами/Stars, с очередью
подтверждения) пока не перенесён — это первая версия; в Mini App на его
месте — заглушка со ссылкой открыть тот же раздел прямо в боте.
