# Assets — реальные изображения персонажей

Сеть в среде разработки этого бота разрешает исходящий HTTPS только на
`github.com`/`raw.githubusercontent.com` (egress-прокси блокирует TCP
CONNECT ко всем остальным хостам, включая Fandom/Wikia, их CDN картинок,
Wikimedia, Imgur, jsDelivr — проверено напрямую `curl`, ответ `403` на
уровне прокси, не сайта). Поэтому реальные рендеры персонажей Steal a
Brainrot скачать из песочницы физически нельзя — сейчас вместо них
фронтенд рисует процедурную «призму» тира (см. `prestigeTile()` в
`webapp/static/js/app.js`): цветной градиент по редкости + инициалы имени.

Как подключить настоящие изображения (когда они появятся — сохранены
вручную со скриншотов/вики/самой игры):

```
webapp/static/assets/
  brainrots/<slug>.png   — портрет персонажа (кейсы, инвентарь, апгрейдер, батл)
  cases/<code>.png       — обложка кейса (пока не используется фронтендом отдельно)
  icons/                 — служебные иконки интерфейса
  ui/                    — прочая графика интерфейса
```

`<slug>` — имя персонажа в нижнем регистре, пробелы на дефисы (see
`bot.data.brainrot_roster.slugify`, например `"Tralalero Tralala"` →
`tralalero-tralala.png`). Код уже подставляет этот путь в `<img src>`
для каждого персонажа (см. `webapp/api.py::_brainrot_json`,
`image_url`) — просто положить файл с правильным именем, БЕЗ изменений
в JS/CSS/Python: `onerror` на призме скрывает файл, если его нет,
`onload` прячет призму и показывает картинку, если файл нашёлся.
