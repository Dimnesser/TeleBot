# Assets

## brainrots/ — официальные рендеры персонажей Steal a Brainrot

`brainrots/<slug>.webp` — внутриигровой рендер персонажа из инфобокса его
статьи на Steal a Brainrot Wiki (https://stealabrainrot.fandom.com), скачан
через MediaWiki API (`prop=pageimages&piprop=original`), обрезан по
прозрачности и уменьшен до 320px. Ничего не перерисовано и не сгенерировано.

Набор персонажей — ровно те, что пользователь прислал на скриншотах
(см. `bot/data/brainrot_roster.py`). `<slug>` — `slugify(name)` из того же
модуля: `"Dug dug dug"` → `dug-dug-dug.webp`.

Тест `tests/test_case_content.py` проверяет, что у каждого персонажа ростера
есть файл и что в папке нет лишних картинок. Если файла нет, фронтенд
показывает честный плейсхолдер «нет ассета», а не подменную картинку.

Добавить персонажа: запись в `ROSTER` (имя/тир/цена/доход — из инфобокса
вики, ценность — из источника цен) + файл `brainrots/<slug>.webp` из той же
статьи вики.

Изображения — собственность разработчиков Steal a Brainrot; вики
распространяет материалы по CC BY-SA.

## Кейсы

Оформление кейсов — собственное, рисуется кодом
(`webapp/static/js/case-themes.js`, SVG-силуэт темы + рендер самого
дорогого брейнрота кейса). Отдельных картинок кейсов нет.
